# ## PWA Installation

The application can be installed as a Progressive Web App (PWA) on both iOS and Android devices.

### 📱 iOS (iPhone / iPad)

1. Open **Safari** on your iPhone or iPad.

2. Go to the application:

   [https://funny-kulfi-6ac90b.netlify.app/](https://funny-kulfi-6ac90b.netlify.app/)

3. Tap the **Share** button (the square with the arrow pointing upward).

4. Scroll down and select **Add to Home Screen**.

5. If available, enable **Open as Web App**.

6. Tap **Add**.

7. The application will appear on your Home Screen.

8. Open the application from the Home Screen to use it as a PWA.

> **Note:** On iOS, the PWA should be installed using Safari. Other browsers may not provide the same "Add to Home Screen" installation experience.

### 🤖 Android

1. Open **Google Chrome** on your Android device.

2. Go to the application:

   [https://funny-kulfi-6ac90b.netlify.app/](https://funny-kulfi-6ac90b.netlify.app/)

3. Wait for the application to load.

4. Tap the **three-dot menu (⋮)** in the top-right corner.

5. Select **Add to Home screen** or **Install app**.

6. Confirm by tapping **Install** or **Add**.

7. The application will appear on your Home Screen.

8. Open it from the Home Screen to use it as a PWA.

> **Note:** Depending on the Android device and Chrome version, the installation option may appear as **Install app**, **Add to Home screen**, or as an installation prompt automatically displayed by the browser.
